# Movie Application

## Short Description

A full-stack movie browsing application built with Node.js, Express, and React that fetches and displays real-time movie data from the TMDB API.

## Features

*   **Node.js/Express Backend:** Robust server-side architecture for API routing and data handling (4:00).
*   **TMDB Integration:** Dynamic fetching of popular movie data via third-party API (7:51).
*   **Secure Environment:** Uses `.env` files to manage sensitive API keys securely (9:39).
*   **Responsive Frontend:** Seamless React integration for displaying movie lists and details (15:10).

## Installation

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd movies-app
    ```

2.  **Prerequisites:**
    Ensure Node.js is installed on your machine. Verify with `node -v` (1:27).

3.  **Install Dependencies:**
    ```bash
    npm install express dotenv
    ```

4.  **Environment Setup:**
    Create a `.env` file and add your `API_KEY` obtained from the TMDB website (10:44).

## Usage

To start the backend server:
```bash
node index.js
```

The server will run on `http://localhost:3001` (5:11).
